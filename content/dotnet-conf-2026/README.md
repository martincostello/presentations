## Abstract

> ASP.NET Core 11 includes built-in support for OpenTelemetry metrics and traces
> which follow the OpenTelemetry Semantic Conventions for HTTP Servers.
>
> But what are Semantic Conventions?
>
> In this session we'll go into what the OpenTelemetry Semantic Conventions are
> and where ASP.NET Core 11 implements them.
>
> Then we'll show how you can leverage them to validate your telemetry and generate
> consistent dashboards and alerts for polyglot services across your environment,
> no matter what programming languages they're written in.
